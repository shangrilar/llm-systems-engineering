# Embedding 층에서 LM Head까지: 그림의 입력과 출처

이 글의 그림 1~5는 직접 작성한 SVG 도식이다. 한국어·영어판은 같은 도형, 좌표, 색, 글자 크기와 예시 수치를 사용한다. 본문은 글꼴 차이에 영향을 받지 않도록 가로 2,400px PNG를 사용하며, 수정 가능한 SVG도 같은 이미지 폴더에 포함했다.

## 토크나이저 예시

- 입력: `Hello world!`
- 토큰: `Hello`, ` world`, `!`
- ID: `9707`, `1879`, `0`
- 토크나이저: `Qwen/Qwen3-0.6B`
- revision: `c1899de289a04d12100db370d81485cdf75e47ca`
- [tokenizer.json 원본](https://huggingface.co/Qwen/Qwen3-0.6B/blob/c1899de289a04d12100db370d81485cdf75e47ca/tokenizer.json)
- tokenizer.json SHA-256: `aeb13307a71acd8fe81861d94ad54ab689df773318809eed3cbe794b4492dae4`

해당 tokenizer.json을 `tokenizers.Tokenizer`로 실행한 결과이며, 특수 토큰을 추가하지 않았다. 그림의 `␣`는 실제 입력의 공백을 보이게 표시한 기호다. 이는 토크나이저 예시를 위한 선택이며 시리즈 전체의 기준 모델을 확정한 것은 아니다.

## 설명용 수치와 생략

- d = 4와 모든 임베딩·출력 벡터·logits 값은 직접 만든 교육용 예시다. 모델 가중치나 성능 측정 결과가 아니다.
- 그림 1은 전체 경로를 단순화한 것으로 최종 정규화 등의 세부 단계가 생략되어 있다.
- 그림 3의 테이블은 ID 순서로 표시하며 일부 행을 생략했다. 선택한 세 행만 강조하고, 출력은 입력 순서인 9707, 1879, 0을 따른다. ①②③은 입력 순서 표시다.
- 그림 4와 5의 벡터는 설명의 연속성을 위한 도식이다. 실제 모델의 연속 실행 결과나 최종 정규화 계산을 나타내지 않는다.
- 본문 이미지를 누르면 원본 PNG로 이동해 확대할 수 있다.
